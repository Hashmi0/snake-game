# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User-approved TypeScript, Vite, Three.js, native HTML/CSS, Web Audio, Vitest, Playwright, npm.
## Users
People who enjoyed Nokia Snake and want casual browser play on a smartphone or laptop.
## Product Purpose
A polished single-player game that preserves classic grid rules while adding expressive 3D presentation, animation and sound.
## Operating Context
Short play sessions using swipes/touch buttons on mobile and keyboard on desktop. Static hosting on GitHub Pages or Vercel.
## Capabilities and Constraints
The full approved specification lives in docs/BUILD_PLAN.md. Local scores/settings, no backend or account. Mobile and desktop equally important.
## Brand Commitments
Snake Garden: sculpted garden, rounded green snake, colorful fruit, warm lighting, cream/dark-green interface. Friendly, concise language. The user approved this direction and delegated routine creative decisions.
## Accessibility & Inclusion
Reduced motion, visible focus, touch alternatives, readable controls, mute, resilient local storage.
